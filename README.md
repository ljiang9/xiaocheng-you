# 小城游 · 文旅局模拟器

你是某十八线小城的文旅局长。国庆 7 天，每天把 10 点**情绪价值点数**
投到 5 个项目，应对一波波热搜级随机事件。7 天后按**接待量 / 口碑 / 局长发量**
结算。祝局长头发安好。

灵感来源：2026 国庆"小城游 / 县城游"爆火热搜 ——
"景区热度前十被小城包揽""情绪价值拉满""特种兵旅游""景区限流劝退"。

## 玩法

每天分配恰好 10 点到 5 个项目（5 个整数，空格分隔）：

| 项目 | 效果 |
|---|---|
| 美食 | 客流 +0.8万/点，口碑 +1/点；网红探店事件的关键 |
| NPC互动 | 口碑 +3/点（情绪价值拉满），客流 +0.3万/点；特种兵团的最爱 |
| 夜游 | 客流 +1.0万/点，简单粗暴 |
| 限流 | 客流多了不挨骂的本钱；爆单/本地人被堵事件的减伤 |
| 修厕所 | <2 点必出事（全网热搜 #小城厕所#），≥2 点反而涨口碑 |

每天还会随机触发 1 个事件（梗浓度超标）：

- **游客爆单**：客流暴涨，限流不够就被骂上热搜
- **万岁山式22倍热度**（第 3 天起）：一夜爆火，接待 +30万，局长一夜白头
- **景区被迫限流劝退**：客流太多时的官方"求放过"
- **本地人上班被堵**：旅游城市的经典副作用
- **特种兵旅游团杀到**：NPC 投入够就五星好评，不够就"就这？"
- **网红探店**：美食投入够就被吹爆
- **厕所告急**：修厕所的意义在此刻具象化
- **风平浪静**：难得清闲，局长多长两根头发

## 结局（7 天后结算）

| 结局 | 条件 |
|---|---|
| 下一个淄博 | 接待 ≥80万 且 口碑 ≥75 |
| 细水长流小城 | 口碑 ≥60 且 接待 ≥40万 |
| 劝退成功 | 接待 <25万 且 口碑 ≥50（人少景美，本地人狂喜） |
| 局长连夜跑路 | 口碑 <35 或 发量 <25 |
| 平平无奇小城 | 其他（热搜查无此城） |

## 运行

```bash
# 人机对战（需要终端）
python3 -m xiaocheng_you

# AI 局长自动玩 10 局，看结局分布
python3 -m xiaocheng_you --auto --games 10 --seed 42

# 看某一局的完整战报
python3 -m xiaocheng_you --auto --games 1 --seed 7 --verbose
```

## 已知局限（诚实版）

- 数值是拍脑袋调的，平衡性未经大规模仿真；AI 局长只是固定规则贪心，不算聪明
- 事件纯随机 + 简单条件，没有真正的"热度传播"模型
- 文本界面，无图形/存档；Python 3.10+，纯标准库
